# Trip Planner V8

- Faiz (`faiz`) is now treated as the workspace administrator.

- Admins can open, archive/restore, and delete any trip.
- Added a global announcement banner visible to signed-in travelers.
- Bumped PWA cache to `trip-planner-v8`.
