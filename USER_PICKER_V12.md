# V12 User Picker Upgrade

The Create Plan and Invite People flows now show all registered users as tick boxes.

- Current user is excluded automatically.
- Select all is available.
- Create Plan uses checked users as trip members and availability targets.
- Invite People supports selecting multiple users in one action.
- Users already in the trip are skipped when sending invitations.
- Trip group chat membership is synced for all selected invitees.
