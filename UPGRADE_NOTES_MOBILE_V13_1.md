# Mobile Optimized V13.1

- Responsive mobile layout for phones and small tablets.
- Bottom navigation replaces the desktop sidebar on screens <= 760px.
- Safe-area support for iPhone/Android gesture areas.
- Full-width mobile dialogs with scrollable content.
- Mobile-friendly trip forms, calendars, chat, user pickers and admin tables.
- Touch-friendly controls and 16px form text to reduce mobile browser zoom.
- Updated PWA cache name so installed apps can pick up the new UI.
